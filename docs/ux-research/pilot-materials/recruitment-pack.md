# 招募启动包（6–12 岁）

> **使用方法：** 本文里的方框是**可直接复制**的材料。打印用的那两份
> （`handover-card.md`、`verdict-card.md`）单独成文件，方便直接打印。
>
> 版本：`2026-09-21`。改了任何一份材料就把这个日期改掉，并在实验者日志里记一笔 ——
> 否则"用的是哪一版问卷"事后说不清。
>
> 判据与阈值见 [`../phase0-evaluation.md`](../phase0-evaluation.md) §8；
> 执行流程见 [`../pilot-protocol.md`](../pilot-protocol.md)。

---

## 0. 发出邀请之前（半天）

| 顺序 | 事情 | 做完的标志 |
| --- | --- | --- |
| 1 | **监护人知情同意必须先过一遍**（见 §4 的模板 + 取舍说明） | 有人（法务/伦理审查/至少一位非项目成员）签字确认过 |
| 2 | 想清楚"给孩子什么回报" | 写下来。不要承诺 App 内奖励，也不要用钱买家长的好评 |
| 3 | 准备好设备与规模 | 每户一台设备；如果需要一机多户，明确"换户之前必须导出+清空" |
| 4 | 定好年龄带配额 | 5 档 × 3–4 户，写在纸上，招满一档就停 |
| 5 | 建一个**实验者日志**（一个文件或一张表） | 每次接触都能追加一行：日期、户号、做了什么、异常 |

> **不要跳过第 1 项。** 这份原型收集的是 6–12 岁儿童的行为数据（哪怕是匿名的），
> 本文给的同意书是**骨架**，不是可以直接用的法律文件。

## 1. 招募文案

### 1.1 短版（微信群 / 朋友圈，约 120 字）

```text
【招募】7 天「成长世界」体验，找 6–12 岁的小学生家庭

我们在做一个给孩子的成长小世界：孩子自己选一件小事做到（比如"数学 15 分钟"），
世界里的小动物和植物就会变化。想看看孩子会不会第二天自己想起来再打开它。

- 需要：一台孩子能用的手机或平板，连续 7 天，每天几分钟
- 不收费，也**不会**给孩子排名、积分或任何比较
- 我们想要的是真实的反应，所以**请不要提醒孩子打开**（这一点很重要）
- 数据只有匿名的使用记录，没有姓名、学校、联系方式

愿意的话回复我，我会先问几个小问题。
```

### 1.2 长版（一对一私聊用，约 250 字）

```text
我在做一个小实验，想请你和孩子帮个忙。

这是一个给小学生用的「成长世界」：孩子每天自己挑 1–3 件小事做到
（数学计算 15 分钟、上课举手 1 次、运动 20 分钟……），做完之后世界里的小动物
和植物会发生变化。7 天一个完整的小故事。

我想验证的是：**孩子第二天回来，是因为他自己想看看世界变成什么样，
而不是因为有人提醒他。** 所以有几件事想先说清楚：

1. 这一周**尽量不提醒**孩子打开。如果提醒了也很正常（我不会因此觉得怎样），
   只是请如实告诉我——这一条本身就是我要测的东西。
2. 我不会给孩子排名、积分或跟别人比较，做少了也不会有任何惩罚。
3. 结束后我会问你两三个问题（孩子有没有主动给别人看、有没有哪天不想打开）。
4. 收的数据是匿名的使用记录，不含姓名和学校。你随时可以让我删掉。

会占用你大约 10 分钟（一开始的设备设置 + 结束后的几个问题），
孩子那边每天几分钟。你方便的话我现在问你几个筛选问题？
```

**不要说的话**（会提前污染结果）：

- ❌「你可以看看孩子的专注力有没有改善」→ 变成家长工具，家长会开始盯
- ❌「帮我们测试一下这个 App」→ 孩子会以为是任务，主动性测不到
- ❌「有小红花/积分」→ 这正是我们要对比的机制

## 2. 筛选问卷（招募时，约 3 分钟）

> 实验者照着念、照着填。**不要**把这份问卷发给孩子。

```text
家庭编号：F___      填表日期：____-__-__      记录人：______

1. 孩子现在几年级？            ______ 年级
   （→ 实验者换算年龄带，不要让孩子自己报年龄）

2. 家里有没有一台孩子可以每天用的手机/平板？
   [ ] 有，孩子自己拿得到   [ ] 有，但要家长给   [ ] 没有

3. 接下来这一周，有没有考试、旅行、生病、比赛等会打乱日常的安排？
   [ ] 没有（可以开始）   [ ] 有 → 换一周再开始，约下次时间：______

4. 孩子平时用平板/手机一般做什么？大约每天多久？
   ______________________________________________

5. 你觉得孩子在注意力或学习上，目前有没有一些困难？
   [ ] 没有   [ ] 有一些   [ ] 不确定
   如果有，具体是：________________________________

6. 这一周你能不能做到不主动提醒孩子打开这个 App？
   [ ] 能   [ ] 我可能会提醒 → 仍然可以参加，但这户的 SAAR 单独标注

7. 家里谁会陪孩子用完这 7 天？（关系即可，不要写姓名）
   ______________________________________________

结果： [ ] 入组，年龄带 ______   [ ] 本批不入组，原因：__________
```

**第 6 题怎么用：** 答"我可能会提醒"不是排除标准。它是**分析标签** ——
这户的 SAAR 单独列，不进主数字，也不要因为家长诚实回答就不让他参加。

## 3. 家长症状清单（交接设备时填，约 2 分钟）

> 交给家长的原话：「这不是测验，也没有对错。我只想大概知道孩子平时做事情的
> 状态，这样分析的时候能把'孩子本来坐不坐得住'和'这个 App 有没有用'分开看。」

```text
家庭编号：F___      填表人：家长      日期：____-__-__

请按最近两周的情况，在每项后选：从不 / 有时 / 经常

1.  做需要安静坐下来的事情时容易分心。        [从不] [有时] [经常]
2.  需要反复提醒才能开始做一件事。            [从不] [有时] [经常]
3.  坐不住，喜欢站起来走动。                  [从不] [有时] [经常]
4.  容易忘记刚交代的事情。                    [从不] [有时] [经常]
5.  完成任务比同龄孩子慢。                    [从不] [有时] [经常]
6.  遇到不会的题容易放弃。                    [从不] [有时] [经常]
7.  情绪起伏大，容易着急。                    [从不] [有时] [经常]
8.  能自己安排好看屏幕以外的时间。            [从不] [有时] [经常]
9.  学校老师提过注意力或纪律方面的问题。      [从不] [有时] [经常]
10. 学习上目前有明显困难（哪一科）：____________  [从不] [有时] [经常]
```

**只在内部用。** 不进任何给家长看的报告，不做分数报告，只做"低/中/高"分层标签。

> ⚠️ 这是自编的轻量工具，**只用于内部分层**。要正式发表或给家长反馈，
> 必须换成有版权许可与常模的标准化量表（如 SNAP-IV、SDQ）。

## 4. 监护人知情同意书（模板）

> ⚠️ **这是骨架，不是终稿。** 使用前必须由懂本地法规的人过一遍。
> 方括号里是必须按实际项目填/删的地方。

```text
研究参与知情同意书

项目名称：[7 天成长世界 · Phase 0 原型测试]
实施方：[公司/团队名称]
联系人及联系方式：[姓名、电话/邮箱]
版本日期：2026-09-21

一、这个项目是什么
我们在测试一个给小学生使用的原型应用。孩子每天可以从一组预设的小事里
自己选择 1–3 件做到（例如"数学计算 15 分钟""上课举手回答 1 次"），完成后，
应用里的虚拟世界（一棵植物、一只小动物）会发生相应的变化，7 天形成一个小故事。

二、这不是什么
- 不是课程，不提供教学内容，也不是学习工具。
- 不是测评，不会给孩子打分、排名，也不会与其他孩子比较。
- 不是治疗或诊断工具，不能替代任何专业评估。

三、孩子需要做什么
连续 7 天，每天使用几分钟，自己选择目标并在完成后自行确认。
没有完成任何一天都不会有任何惩罚，世界不会消失、不会枯萎。

四、我们会收集什么
- 匿名的使用记录：打开时间、选择了哪些目标、是否标记完成、看了哪些界面反馈。
- 一个随机生成的匿名编号（保存在设备本地），它不与姓名、学校、联系方式关联。
- 孩子对两个问题的选择（"今天是怎么打开这个世界的"）以及监护人填写的一份
  简短问卷。

五、我们不会收集什么
- 不收集姓名、生日、学校、联系方式、照片、声音或位置。
- 不录制屏幕，不采集键盘输入，不使用广告或社交功能。
- 不采集任何通讯录、相册或其他应用的数据。

六、数据如何使用和保存
- 数据仅用于评估这个原型是否值得继续研发，用于内部分析报告。
- 报告只呈现汇总与匿名信息，不会出现可以识别到某个孩子的描述。
- 保存期限：[例如：项目结束后 6 个月内删除]。
- 数据处理方：[仅项目团队 / 使用的第三方分析服务名称及所在地]。

七、自愿与退出
- 参与完全自愿。孩子或监护人可以在任何时间退出，无需说明理由。
- 退出后可以要求删除已收集的数据，联系方式见文首。
- 不参与或退出不会带来任何不利影响。

八、风险和不适
本项目的风险不高于日常使用手机应用。若孩子在使用中感到不适或情绪波动，
可以立即停止。监护人可随时联系我们。

九、监护人确认
我已阅读并理解以上内容，我有权为该儿童作出同意决定，我自愿让孩子参与本项目。

监护人签名：____________  日期：____-__-__
与孩子关系：____________  联系电话：____________

（可选）孩子本人知情：我们已用孩子能理解的话告诉他/她这是做什么的。
```

**同意书之外还要做的三件事**（比签字更容易被忽略）：

1. **用孩子能懂的话说一遍。** 6 岁孩子听不懂"数据""匿名"。可以说：
   「这个小岛会记住你做过的事，但不会记住你是谁。」
2. **告诉孩子可以随时停下。** 而且真的做到——孩子说不想玩了就停。
3. **把"不提醒"写进给家长的说明里**，不要只口头说（见 §5 交接卡背面）。

## 5. 交接设备时的实验者动作（照着做，顺序不能变）

详见 [`../pilot-protocol.md`](../pilot-protocol.md) §2。这里只列**最容易漏的三步**：

1. **孩子不在场时**录入年龄带（`?debug=1` 面板最上面），确认不再是「未记录」。
2. 关掉 `?debug=1`，回到普通网址，**确认是欢迎页**，再把设备交给孩子。
3. 孩子自己走完欢迎页。**不解释、不代点。** 孩子问"这是什么"就答"你自己看看"。
   只在明显卡住超过 1 分钟时给一次最小提示，并**在交接卡上记一笔**。

打印用：[`handover-card.md`](./handover-card.md)

## 6. 每次接触的脚本（S1 / S3 / S4）

### S1 · Day 1 之后（打电话或微信，5 分钟）

只问两句，**不要扩展**：

```text
1. 今天孩子有没有自己又打开过？   [有，几次：___] [没有] [不确定]
2. 有没有哪里卡住、或者他问了你什么？  ______________________
```

不要问"他喜欢吗"。不要鼓励。不要预告"明天会有变化"。

### S3 · Day 7 之后（10 分钟，含孩子在场的探针）

**A. 孩子在场时的 3 分钟延迟回忆探针**（完成当天目标 20 分钟后）：

```text
「刚才小光做了什么？」
孩子回答：____________________________________________
[ ] 说得出"我做了什么 → 世界怎么变"的因果
[ ] 只记得 +10 / 有个动画
[ ] 说不出来

「那扇门后面有什么？」
孩子回答：____________________________________________
[ ] 有具体想象、带着期待   [ ] 不知道 / 打不开   [ ] 没提到门
```

**B. 家长 30 秒旁证**（孩子不在场时问）：

```text
「这一周孩子打开这个 App 的时候，通常是谁先起的头？」
[ ] 孩子自己拿出来就打开了
[ ] 我或家人叫他/她来打开
[ ] 我也不太确定
```

> **只有「确认」，没有「否认」。** 这个问题无论怎么答，**都不改变孩子的任何
> 东西**（P5）。它是 SAAR 的校验列，不是替代品。

**C. 家长两问：**

```text
1. 这一周孩子有没有主动把这个世界给别人看？（给谁、什么反应）
   ____________________________________________________
2. 有没有哪一天，孩子因为"世界没变化"而不再打开？是哪一天？
   ____________________________________________________
```

### S4 · Day 7 + 3 天（5 分钟，**必须**）

补导一次数据。这是主验收点唯一能取到的地方。
步骤见 [`../pilot-protocol.md`](../pilot-protocol.md) §4。

## 7. 实验者日志（每户一行，别事后补）

| 日期 | 户号 | 接触 | 做了什么 | 异常 / 备注 |
| --- | --- | --- | --- | --- |
| | | T0 | 录入年龄带 6-7、家长填表、孩子自己完成欢迎页 | 在"选目标"卡了 70 秒，给了一次提示 |
| | | T1 | 电话 | 家长说孩子自己打开过一次 |
| | | T3 | 探针 + 旁证 | 孩子能说出"星星多了一颗" |
| | | T4 | 补导 `F03-d11.json` | D8+ 显示 2 天 |

**日志要记的三类异常**（它们往往就是结论本身）：

1. 孩子卡住的具体位置 → 可用性缺陷，不是动机问题
2. 家长承认提醒过 → 这户 SAAR 单独标注
3. 有一天孩子"不想打开"和家长的解释 → 定性证据，比留存曲线更有信息
