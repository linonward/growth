# Pilot 材料（6–12 岁）

可复制、可打印的成套材料。使用方法与完整流程见 [`../pilot-protocol.md`](../pilot-protocol.md)；
判据与阈值的出处见 [`../phase0-evaluation.md`](../phase0-evaluation.md) §8。

| 文件 | 给谁用 | 什么时候 |
| --- | --- | --- |
| [`recruitment-pack.md`](./recruitment-pack.md) | 实验者 | 招募前读一遍；发邀请、填筛选问卷、交接时都要用 |
| [`handover-card.md`](./handover-card.md) | **打印**给实验者 + 家长 | 每次设备交接（T0） |
| [`verdict-card.md`](./verdict-card.md) | **打印**给实验者 | 招募**之前**把阈值填好；数据分析时只填数 |

版本：`2026-09-21`。改了任何一份材料就改这个日期，并在实验者日志里记一笔 ——
否则"用的是哪一版"事后说不清。

> ⚠️ `recruitment-pack.md` 里的**知情同意书是骨架**，方括号处要按实际项目填写，
> 且**使用前必须由懂本地法规的人（法务或伦理审查）过一遍**。
> 其中的家长症状清单是自编工具，**只用于内部分层**；要发表或给家长反馈，
> 需换成有版权许可与常模的标准化量表。
